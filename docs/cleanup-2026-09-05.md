# Review cleanup — 2026-09-05

This is the implementation follow-up to [the baseline review](code-review-2026-09-05.md).
The [project handoff](project-handoff.md) remains the current operational roadmap;
long experiment narratives preserve historical evidence rather than current task order.

## Changes

- **Checkpoint allocation:** validate nonzero dimensions, checked area, tile count,
  lifetime key space, and every live key before rebuilding derived storage. Topology
  reservation is fallible. `CheckpointLimits.max_cell_slots` defaults to 4,000,000
  and bounds historical key space independently of `max_cells`, which bounds
  live cells. Hosts should choose both limits for their resource budget. Sparse old
  survivors remain valid within the configured lifetime limit. Game save schema 12
  persists the new stream limit; canonical checkpoint schema 6 is unchanged.
- **Validation isolation:** assign one training/validation role per source seed over
  the union of all eligible demonstration datasets. Reject datasets that cannot
  form both required partitions. Dataset order cannot change the assignment.
  The partition implementation is isolated in `behavior_cloning/dataset_partition.rs`.
- **Policy compatibility:** `policy_artifact::load_behavior_clone` owns admission and
  model migration for all artifact-based consumers. Schemas 22–29 and 31–35 are
  supported; experimental schema 30 is rejected. Schema-specific regression
  fixtures check exact output agreement with the existing migration operations.
- **Execution identity:** cloning schema 35 binds ABI, observation/action encoding,
  private-memory format, expert routing, and source-build provenance. Training
  schema 45 binds the same execution semantics. Legacy cloning imports run under
  current semantics and require fresh ecological qualification. They do not
  promise historical router behavior. Exact training resume requires the original
  source build and numerical backend; compatible policy-only imports remain available.
  Feeding evaluation, layout, and transition-result reuse requires the same source
  build, preventing old evidence from being labeled as new execution.
- **Build provenance:** source-content digests cover the engine, interface, RL code,
  maintained Mind sources, relevant configuration and manifests. Git worktree/ref
  indirection is resolved. Source edits and additions invalidate provenance even
  without a commit; source archives and explicit revision overrides still carry
  the actual content digest. This is source identity, not a compiler/container digest.
- **Viewer scaling:** `match-history.js` owns reversible sparse history and incremental
  aggregate metrics. It retains changed values instead of cloning entire boards
  periodically. Indexing yields between chunks and cancels superseded loads. Input
  validation includes a combined retained-value budget; it is not an exact byte cap.

- **Lifetime storage:** [sparse cell/scheduler pages and a compact hash tree](lifetime-storage.md)
  replace allocations indexed by all historical cell keys. Empty pages are released;
  cell and private-memory commitments retain only live keys. Canonical hash format 7,
  checkpoint schema 6, and simulation rules are unchanged. Cell storage and the compact
  cell Merkle tree now live in separate modules from the resolver.
- **Observation boundary:** `resolution/reference/observation.rs` now owns Mind
  projection, reusable batch views, masking and ABI cue conversion. The 470
  extracted lines are text-identical to their prior resolver blocks; existing
  public method and batch-type paths remain available. Dedicated visibility,
  anonymity and scratch-reuse harnesses cover this boundary.
- **Passive kernels:** `resolution/reference/passive.rs` now owns plant growth,
  digestion, metabolism, signal decay and diffusion helpers. The 439-line block
  preserves its arithmetic after adding only parent-module visibility and
  formatting. Scheduling, mutation journals and active-frontier orchestration
  stay in the resolver; native/WASM and full canonical oracles validate the split.
- **Experiment navigation:** [the experiment index](experiment-index.md) covers
  all 50 retained sweep directories, linking dispositions and successors while
  distinguishing raw plans from completed execution and scientific qualification.
- **Artifact read limits:** [one shared bounded reader](artifact-io-2026-09-11.md)
  replaces size-check/reopen sequences across 23 RL modules. It checks and reads
  the same handle and enforces the cap on actual bytes, including growth after
  metadata inspection; existing format and semantic checks remain in place.
